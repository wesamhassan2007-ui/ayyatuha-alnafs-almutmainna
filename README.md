# المرحومين من آل بغدادي وآل أيوب

نسخة جديدة مستقلة بالكامل (مستودع ومشروع Firebase منفصلان).

## قبل النشر

1. أنشئ مشروع Firebase جديد، وفعّل Authentication ← Email/Password، وأنشئ Firestore بوضع Production.
2. انسخ إعدادات الويب (firebaseConfig) والصقها في index.html، في قسم FIREBASE_CONFIG.
3. ضع رابط GitHub Pages الجديد في APP_URL.
4. الصق محتوى firestore.rules في Firestore ← Rules.

## أول دخول

أول حساب يسجّل دخوله يصبح مدير المشروع ومدير الصفحتين، فيجب أن يدخل صاحب المشروع الجديد أولاً قبل نشر الرابط.

## الصفحات

- صفحة أموات آل بغدادي
- صفحة أموات بيت أيوب

الأسماء تُضاف من داخل التطبيق.
